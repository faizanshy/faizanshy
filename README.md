# Faizan Shy Portfolio

Minimal static portfolio website for GitHub Pages.

## Files
- `index.html`
- `style.css`
- `script.js`
- `assets/favicon.svg`

## GitHub Pages
1. Create a GitHub repository.
2. Upload all files and the `assets` folder to the repository root.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Choose `main` and `/ (root)`.
6. Save.

No npm, Node.js, build step, backend, database, or API is required.
